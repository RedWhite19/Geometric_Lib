# Документация проекта geometric_lib

Документация по библиотеке геометрических фигур, содержащая описание работы функций, примеры их вызова и историю изменений.

## 1. Общее описание решения

Библиотека `geometric_lib` предоставляет набор функций для вычисления геометрических параметров плоских фигур: **круга (circle)**, **квадрата (square)**, **прямоугольника (rectangle)** и **треугольника (triangle)**.

Библиотека позволяет рассчитывать:
* **Площадь ($S$)** фигуры по её линейным размерам.
* **Периметр ($P$)** или длину окружности.

## 2. Описание функций с примерами вызова

### 2.1. Работа с кругом (`circle.py`)

#### `area(r)`
Принимает радиус круга $r$ и возвращает его площадь.
* **Формула:** $S = \pi r^2$
* **Параметры:** `r` (int/float) — радиус круга.
* **Возвращаемое значение:** float — площадь круга.

**Пример вызова:**
```python
import circle

res = circle.area(5)
print(res)  # Выведет: 78.53981633974483
```

#### `perimeter(r)`
Принимает радиус круга $r$ и возвращает длину его окружности.
* **Формула:** $P = 2\pi r$
* **Параметры:** `r` (int/float) — радиус круга.
* **Возвращаемое значение:** float — длина окружности.

**Пример вызова:**
```python
import circle

res = circle.perimeter(5)
print(res)  # Выведет: 31.41592653589793
```

### 2.2. Работа с квадратом (`square.py`)

#### `area(a)`
Принимает длину стороны квадрата $a$ и возвращает его площадь.
* **Формула:** $S = a^2$
* **Параметры:** `a` (int/float) — сторона квадрата.
* **Возвращаемое значение:** int/float — площадь квадрата.

**Пример вызова:**
```python
import square

res = square.area(4)
print(res)  # Выведет: 16
```

#### `perimeter(a)`
Принимает длину стороны квадрата $a$ и возвращает его периметр.
* **Формула:** $P = 4a$
* **Параметры:** `a` (int/float) — сторона квадрата.
* **Возвращаемое значение:** int/float — периметр квадрата.

**Пример вызова:**
```python
import square

res = square.perimeter(4)
print(res)  # Выведет: 16
```

### 2.3. Работа с прямоугольником (`rectangle.py`)

#### `area(a, b)`
Принимает стороны прямоугольника $a$ и $b$ и возвращает его площадь.
* **Формула:** $S = a \cdot b$
* **Параметры:**
  * `a` (int/float) — первая сторона прямоугольника.
  * `b` (int/float) — вторая сторона прямоугольника.
* **Возвращаемое значение:** int/float — площадь прямоугольника.

**Пример вызова:**
```python
import rectangle

res = rectangle.area(3, 5)
print(res)  # Выведет: 15
```

#### `perimeter(a, b)`
Принимает стороны прямоугольника $a$ и $b$ и возвращает его периметр.
* **Формула:** $P = 2(a + b)$
* **Параметры:**
  * `a` (int/float) — первая сторона прямоугольника.
  * `b` (int/float) — вторая сторона прямоугольника.
* **Возвращаемое значение:** int/float — периметр прямоугольника.

**Пример вызова:**
```python
import rectangle

res = rectangle.perimeter(3, 5)
print(res)  # Выведет: 16
```

### 2.4. Работа с треугольником (`triangle.py`)

#### `area(a, h)`
Принимает сторону треугольника $a$ и проведенную к ней высоту $h$, возвращает площадь треугольника.
* **Формула:** $S = \frac{a \cdot h}{2}$
* **Параметры:**
  * `a` (int/float) — сторона треугольника.
  * `h` (int/float) — высота, опущенная на сторону `a`.
* **Возвращаемое значение:** float — площадь треугольника.

**Пример вызова:**
```python
import triangle

res = triangle.area(4, 5)
print(res)  # Выведет: 10.0
```

#### `perimeter(a, b, c)`
Принимает три стороны треугольника $a$, $b$, $c$ и возвращает его периметр.
* **Формула:** $P = a + b + c$
* **Параметры:**
  * `a` (int/float) — первая сторона.
  * `b` (int/float) — вторая сторона.
  * `c` (int/float) — третья сторона.
* **Возвращаемое значение:** int/float — периметр треугольника.

**Пример вызова:**
```python
import triangle

res = triangle.perimeter(3, 4, 5)
print(res)  # Выведет: 12
```
